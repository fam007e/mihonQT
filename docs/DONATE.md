# Support MihonQT

MihonQT is free, open source (Apache License 2.0), and will stay that way.

## About donations

The developer hasn't figured out a way to accept donations for MihonQT — there
is no donation account, payment setup, or merchandise for this project, and
none is planned until there is a clear way to do it properly.

## Where your support helps most

If you want to put something back, the best place is **Mihon itself** — the
Android app MihonQT is a port of. Improving Mihon improves the ecosystem this
project is built on:

- **Donate to Mihon:** [mihon.app/donate](https://mihon.app/donate/)
- **Contribute code or translations:**
  [github.com/mihonapp/mihon](https://github.com/mihonapp/mihon)

## Supporting MihonQT without money

- **Report bugs** with reproducible steps in the
  [issue tracker](https://github.com/fam007e/mihonQT/issues) (templates included).
- **Help other users** in the
  [Discord](https://discord.gg/F34duNjTqn).
- **Improve the documentation** — the wiki pages live in `docs/wiki/` of the
  repository.
- **Write extensions** — see [Extensions](Extensions.html).
