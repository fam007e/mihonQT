# Contributing to MihonQT

First off, thank you for considering contributing to MihonQT! It's people like you that make MihonQT such a great tool. This project is maintained by [fam007e](https://github.com/fam007e).

## How Can I Contribute?

### Reporting Bugs

- Use a clear and descriptive title for the issue to identify the problem.
- Describe the exact steps which reproduce the problem in as many details as possible.
- Provide specific examples to demonstrate the steps.
- Describe the behavior you observed after following the steps and explain precisely what is the problem with that behavior.
- Explain which behavior you expected to see instead and why.

### Suggesting Enhancements

- Use a clear and descriptive title for the issue to identify the suggestion.
- Provide a step-by-step description of the suggested enhancement in as many details as possible.
- Provide specific examples to demonstrate the steps.
- Describe the current behavior and explain which behavior you expected to see instead and why.

### Pull Requests

- Fill in the required template.
- Ensure the build passes locally.
- Keep pull requests concise and focused on one change.
- Follow the existing code style of the project.
- For any questions, please open a GitHub Issue.

## Development Setup

1. Clone the repository: `git clone --recursive https://github.com/fam007e/mihonQT.git`
2. Install dependencies (Qt6, etc.).
3. Build using CMake:
   ```bash
   cmake -B build -S .
   cmake --build build
   ```

Thank you for your contributions!
